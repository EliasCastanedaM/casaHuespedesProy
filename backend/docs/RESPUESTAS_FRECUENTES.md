# Respuestas frecuentes con datos verificados

Las consultas claras sobre servicios, niños, mascotas, ubicación y medios de pago
usan los formateadores y fuentes vigentes del hotel, sin clasificación ni redacción
con IA. La normalización reconoce introducciones de cortesía e intención de consulta
(por ejemplo, «quería saber», «me gustaría conocer», «me podrías decir»).

Solo se evita la IA si el mensaje completo pertenece a un dominio de consulta
conocido. Un asunto desconocido, una pregunta mixta, una solicitud de reserva o de
pago y detalles no documentados siguen el flujo de interpretación existente.
No se copian precios ni políticas a un catálogo paralelo.

Las consultas generales de servicios mantienen el resumen, el enlace y la imagen
oficial. Las específicas responden solamente sobre el tema solicitado. Niños y
mascotas consultan reglas verificadas; los números bancarios proceden del registro
vigente. Las consultas no modifican borradores ni crean reservas.

El ahorro es por consulta: el envío directo de la imagen y estas respuestas
deterministas no requieren tokens de IA. Las preguntas ambiguas y las reservas
pueden seguir consumiendo tokens. Las tarifas y capacidades se calculan en el
motor existente; esta optimización no aprueba propuestas tarifarias pendientes.
